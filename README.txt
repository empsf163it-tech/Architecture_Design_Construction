HOUSECRAFT DAILY — WEBSITE DEMO
================================

A responsive, seven-page static website concept for architecture, construction and renovation.

PAGES
- index.html — Home
- design-ideas.html — Design Ideas
- build-renovate.html — Build & Renovate
- plans-projects.html — Plans & Projects
- cost-guides.html — Cost Guides
- about.html — About
- contact.html — Contact

ASSETS
- assets/style.css — responsive styles
- assets/site.js — mobile navigation and demo form interactions
- assets/*.svg — original locally bundled architectural illustrations

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Use the navigation to visit all seven pages.

NOTES
- This is a front-end prototype; forms do not send data to a server.
- The layout takes general inspiration from editorial home-improvement websites such as This Old House, but uses an original name, original wordmark, colors, layout, and illustrations. It does not copy the This Old House logo or exact design.
- Before production, replace demo content with your own original content and connect contact/newsletter forms to a secure backend.
